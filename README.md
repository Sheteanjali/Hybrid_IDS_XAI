# Hybrid IDS with XAI (CNN-LSTM)

## How to Run:
1. Place CICIDS2017 CSVs in `data/raw/`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the trainer: `python main.py`

## Project Goal:
To build a high-accuracy Intrusion Detection System (98%+) using a hybrid 
CNN-LSTM model and explain its decisions using SHAP values.
